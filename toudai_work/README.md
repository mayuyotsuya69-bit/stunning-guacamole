# 東大推薦スコア 妥当性検証（取り組み④）

志作文 AI評価プロジェクト：東大推薦ポテンシャルスコアの criterion validity 検証。

## ⚠️ 採点基準に関する重要注記
過去答案CSVの「作文AIスコア(合計0-15)」は **旧採点基準** のため解析から **完全排除**。
東大推薦ポテンシャルスコアは現行基準として使用。これに伴い「② 増分妥当性（作文スコアを
超える予測）」は **保留**（過去答案を現行基準で再採点後に実施予定）。

## 成果物
- `analysis_1.py` … ① ROC/AUC（過去データ n=36、潜在スコア→実合否）。作文スコア不使用。
- `analysis_3.py` … ② 交絡調整（現役 n=582、現行基準の作文スコアを統制）
- `fig1_roc.png` … ROC曲線（AUC=0.830, 95%CI 0.70–0.96）
- `fig3_confound.png` … 属性 vs 東大スコア、作文スコア統制前後の偏相関
- `build_deck.js` / `取り組み④_東大推薦スコアの妥当性.pptx` … 決裁用 単体スライド（全4枚）

## 主な結果
- ① AUC=0.830（DeLong CI 0.697–0.963 / bootstrap 0.684–0.944）, Mann–Whitney p=7.8e-4。
  Youden最適閾値64点で感度68%・特異度88%・的中率87%。合格65.3 vs 不合格42.5。
- ② 交絡調整(n=582): 作文AIスコア統制で属性差は大きく縮小。学年 偏相関0.28→0.10、
  高校ランク0.07→0.03、校舎(早稲田塾)生差+17点→統制後ほぼ0。同一属性の作文スコア予測
  β(+0.285)≒東大スコア予測β(+0.278)=差の正体は概ね作文力。性別は未提供。
